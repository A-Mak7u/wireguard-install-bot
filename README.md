# WireGuard + Telegram-бот

Свой VPN-сервер на WireGuard одной командой — и Telegram-бот, через который ключи
выдаются и удаляются прямо с телефона.

Основан на [angristan/wireguard-install](https://github.com/angristan/wireguard-install).

## Что умеет

- ставит WireGuard на чистый VPS и создаёт первый ключ (файл и QR-код прямо в терминале);
- ставит Telegram-бота:
  - **➕ Добавить ключ** — присылает файл `.conf` и QR-код;
  - **🗑 Удалить ключ** — с подтверждением;
  - **📜 Список ключей**;
  - **👥 Клиенты WG** — кто подключён и сколько трафика;
  - **📊 Статус сервера** — WireGuard, нагрузка, память, диск;
- бот слушается только тех, чьи Telegram ID указаны при установке;
- меню в терминале и команды без вопросов — для скриптов.

## Что нужно

- VPS с публичным IP и доступом root;
- Ubuntu 18.04+, Debian 10+, Fedora 32+, CentOS / AlmaLinux / Rocky 8+, Oracle Linux или Arch
  (на Alpine ставится только WireGuard, без бота);
- для бота — Python 3.9+ (в Ubuntu 22.04+ и Debian 11+ уже есть) и аккаунт в Telegram.

Полный сценарий проверен на Ubuntu 24.04 и Debian 12 (см. [тесты](#тесты)).

## Установка

```bash
curl -O https://raw.githubusercontent.com/A-Mak7u/wireguard-install-bot/main/wireguard-install.sh
chmod +x wireguard-install.sh
sudo ./wireguard-install.sh
```

1. Скрипт задаст несколько вопросов про сеть — если не уверен, везде жми Enter.
2. Спросит имя первого клиента (например, `phone`) и покажет QR-код для него.
3. Предложит поставить Telegram-бота. Для этого:
   - открой в Telegram [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай боту
     имя и вставь в терминал токен, который пришлёт BotFather;
   - на вопрос про Telegram ID просто нажми Enter, открой своего бота, нажми «Старт»,
     вернись в терминал и снова нажми Enter — скрипт сам найдёт твой ID.
4. Готово: открой бота и отправь `/start`.

Если у хостинга есть свой фаервол в панели управления — открой в нём UDP-порт WireGuard
(он показан в «📊 Статус сервера»).

## Как подключить устройство

Поставь приложение WireGuard ([iOS, Android, Windows, macOS, Linux](https://www.wireguard.com/install/)),
нажми «Добавить туннель» и выбери импорт из файла или сканирование QR-кода.

Один ключ — одно устройство: если подключить два устройства с одним ключом, они будут
выбивать друг друга.

## Управление из терминала

`sudo ./wireguard-install.sh` открывает меню: добавить, показать и удалить клиентов,
установить или перенастроить бота, удалить WireGuard.

То же без вопросов:

```bash
sudo ./wireguard-install.sh add mama      # создать ключ, печатает путь к конфигу
sudo ./wireguard-install.sh list          # список клиентов
sudo ./wireguard-install.sh revoke mama   # удалить ключ
sudo ./wireguard-install.sh bot           # установить / перенастроить / удалить бота
```

Имя клиента — латиница, цифры, `_` и `-`, не длиннее 15 символов.

## Где что лежит

| Что | Где |
|---|---|
| конфиг сервера | `/etc/wireguard/wg0.conf` |
| настройки установки | `/etc/wireguard/params` |
| конфиги клиентов | `/root/wg0-client-<имя>.conf` (или домашняя папка того, кто запустил `sudo`) |
| бот и его копия установщика | `/opt/wg-bot/` |
| токен и ID админов | `/etc/wg-bot/bot.env` (читает только root) |
| служба бота | `wg-bot` — логи: `journalctl -u wg-bot -f` |

## Обновление и перенастройка бота

Скачай свежий `wireguard-install.sh` и запусти `sudo ./wireguard-install.sh bot` → «Переустановить».
Прежние токен и ID подставятся сами — их можно оставить или поменять.

Если WireGuard когда-то ставился оригинальным
[angristan/wireguard-install](https://github.com/angristan/wireguard-install), этот скрипт
подхватит его настройки и клиентов: формат тот же.

## Установка без вопросов

```bash
sudo AUTO_INSTALL=y CLIENT_NAME=phone \
  INSTALL_BOT=y BOT_TOKEN='123456789:AAH...' BOT_ADMIN_IDS=111111111,222222222 \
  ./wireguard-install.sh
```

Всё, что не указано, берётся по умолчанию: адрес сервера определяется сам, порт выбирается
случайный. Можно задать и остальное: `SERVER_PUB_IP`, `SERVER_PORT`, `CLIENT_DNS_1`,
`CLIENT_DNS_2`, `ALLOWED_IPS`. Учти, что токен в командной строке попадёт в историю shell.

## Удаление

- всё целиком — пункт «Удалить WireGuard» в меню (бот удалится вместе с ним);
- только бота — `sudo ./wireguard-install.sh bot` → «Удалить бота».

## Безопасность

- Токен бота никому не показывай: с ним можно выдать себя за бота.
- В конфиге клиента лежит приватный ключ — отправляй его только тому, чьё это устройство.
- Если ключ утёк или устройство потеряно — удали ключ, и оно сразу потеряет доступ.

## Тесты

`tests/run.sh` поднимает в Docker чистую систему с systemd и проверяет всё по-настоящему:
установку, бота (через поддельный Telegram API — настоящий токен не нужен), команды,
меню, туннель со второго контейнера с выходом в интернет и удаление.

```bash
tests/run.sh                # Ubuntu 24.04
tests/run.sh debian:12
```

## Чем отличается от angristan/wireguard-install

- интерфейс на русском;
- Telegram-бот;
- команды `add` / `list` / `revoke` и установка без вопросов (`AUTO_INSTALL=y`);
- исправлено:
  - новый клиент получает первый свободный адрес (раньше `.2` считался занятым, если был `.25`);
  - удаление клиента не задевает соседние, даже если в конфиге при ручной правке пропали
    пустые строки;
  - при остановке с firewalld интерфейс убирается из зоны, а не добавляется повторно;
  - конфиги клиентов доступны только владельцу;
  - если сервер за NAT, установщик предлагает внешний IP, а не внутренний.
