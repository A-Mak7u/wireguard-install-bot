# AmneziaWG + Telegram-бот

Автоматический установщик VPN-сервера на базе протокола **AmneziaWG** (современное развитие WireGuard с защитой от глубокого анализа сетевых пакетов / DPI) и удобный **Telegram-бот** для мгновенной выдачи ключей и управления сервером с телефона.

Скрипт развёртывает готовый сервер одной командой и создаёт первого клиента с выводом файла и QR-кода прямо в терминал.

---

## 🚀 Возможности

- **Защита от глубокого анализа трафика (Anti-DPI / Obfuscation)**:
  - **Рандомизация заголовков (`H1`–`H4`)**: замена стандартных сигнатур сообщений WireGuard на псевдослучайные 32-битные значения.
  - **Мусорные пакеты (`Jc`, `Jmin`, `Jmax`)**: отправка случайных UDP-пакетов перед handshake, сбивающих эвристические анализаторы.
  - **Паддинг длины (`S1`, `S2`)**: выравнивание размеров сообщений инициализации и ответа для предотвращения детекта по длине пакета.
  - **Калиброванный MTU**: автоматическая подгонка MTU (1360 для мобильных устройств и Linux/Windows, 1376 для macOS) для исключения фрагментации.
- **Оптимизация сетевого стека**:
  - Алгоритм контроля перегрузок **Google BBR v1** + планировщик очередей **FQ (Fair Queueing)**.
  - **TCP MSS Clamping to PMTU**: автоматическая подгонка размера сегмента TCP под туннельный MTU, устраняющая зависания при передаче тяжёлых TLS 1.3 / HTTPS сессий.
- **Telegram-бот для управления**:
  - **➕ Добавить ключ** — мгновенно создаёт клиента, присылает файл `.conf` и QR-код для сканирования камерой телефона;
  - **🗑 Удалить ключ** — удаление пира из сервера на лету без перезагрузки туннеля и с подтверждением;
  - **📜 Список ключей** — вывод всех зарегистрированных клиентов;
  - **👥 Клиенты WG** — мониторинг активных сессий (online за последние 10 минут), счётчики скачанного и отправленного трафика;
  - **📊 Статус сервера** — аптайм, Load Average, использование RAM и диска, статус службы.
  - **Безопасность**: бот реагирует только на указанные Telegram ID администраторов; токен и секреты изолированы в `/etc/wg-bot/bot.env`.
- **Управление через консоль**: интерактивное меню и режим CLI команд без вопросов для автоматизации.

## 📦 Системные требования

- **VPS/VDS** с публичным статическим IPv4 (или IPv6) и доступом `root`.
- **Поддерживаемые ОС**:
  - **Ubuntu 22.04 LTS / 24.04 LTS** (рекомендуется — нативная поддержка через PPA `ppa:amnezia/ppa` и DKMS);
  - **Debian 11 / 12**;
  - Fedora 32+, CentOS / AlmaLinux / Rocky Linux 8+, Oracle Linux, Arch Linux, Alpine Linux.
- **Для бота**: Python 3.9+ (по умолчанию входит во все современные дистрибутивы) и аккаунт в Telegram.

## ⚡️ Быстрая установка

Подключись к серверу по SSH под пользователем `root` (или с `sudo`) и выполни:

```bash
curl -O https://raw.githubusercontent.com/A-Mak7u/wireguard-install-bot/main/amneziawg-install.sh
chmod +x amneziawg-install.sh
sudo ./amneziawg-install.sh
```

*(Также поддерживается обратная совместимость вызова через `wireguard-install.sh`)*.

### Шаги мастера установки:
1. Скрипт определит сетевой интерфейс и предложит параметры по умолчанию — если нет особых требований, везде нажимай **Enter**.
2. Введи имя первого клиента (например, `phone`) — в терминале сразу отобразится QR-код.
3. Мастер предложит установить Telegram-бота:
   - Открой в Telegram [@BotFather](https://t.me/BotFather), отправь команду `/newbot`, задай имя и скопируй полученный токен;
   - Вставь токен в терминал;
   - На вопрос про Telegram ID нажми **Enter**, открой созданного бота в Telegram, нажми **«Старт»**, вернись в консоль и снова нажми **Enter** — скрипт сам автоматически определит твой ID.
4. Готово! Открой бота в Telegram и отправь `/start`.

> [!NOTE]
> Если в панели управления хостинга включён внешний облачный фаервол (Security Groups), убедись, что выбранный UDP-порт туннеля открыт на входящие соединения.

## 📱 Клиентские приложения

Для подключения используй официальные клиенты с поддержкой параметров обфускации:
- **AmneziaWG**: нативные легковесные приложения для [iOS (App Store)](https://apps.apple.com/app/amneziawg/id6478942364), [macOS (Mac App Store)](https://apps.apple.com/app/amneziawg/id6479044238), [Android (Google Play)](https://play.google.com/store/apps/details?id=org.amnezia.awg) и [Windows / Linux (GitHub Releases)](https://github.com/amnezia-vpn/amneziawg-windows-client/releases).
- **Amnezia VPN**: мультипротокольный клиент для всех платформ.

> [!IMPORTANT]
> Один ключ предназначен строго для одного активного устройства. При одновременном подключении двух устройств по одному ключу они будут перебивать маршруты друг друга.

## 🛠 Консольное управление (CLI)

Запуск `sudo ./amneziawg-install.sh` без аргументов открывает интерактивное меню управления.

Для автоматизации или скриптов доступны прямые аргументы:

```bash
sudo ./amneziawg-install.sh add laptop      # Создать клиента и напечатать путь к .conf
sudo ./amneziawg-install.sh list            # Список зарегистрированных клиентов
sudo ./amneziawg-install.sh revoke laptop   # Отозвать и удалить клиента на лету
sudo ./amneziawg-install.sh bot             # Меню перенастройки или удаления бота
```

### Автоматическая тихая установка (без диалогов):

```bash
sudo AUTO_INSTALL=y CLIENT_NAME=phone \
  INSTALL_BOT=y BOT_TOKEN='123456789:AAH...' BOT_ADMIN_IDS=111111111 \
  ./amneziawg-install.sh
```

## 📁 Пути к файлам конфигурации

| Назначение | Путь в системе |
|---|---|
| Конфигурация сервера | `/etc/amnezia/amneziawg/awg0.conf` (или `/etc/wireguard/awg0.conf`) |
| Сохранённые параметры сети | `/etc/wireguard/params` |
| Готовые файлы клиентов | `/root/awg0-client-<имя>.conf` (или в домашней папке пользователя) |
| Каталог Telegram-бота | `/opt/wg-bot/` |
| Секреты и токены бота | `/etc/wg-bot/bot.env` (доступ только root `0600`) |
| Системная служба бота | `systemctl status wg-bot` (логи: `journalctl -u wg-bot -f`) |
